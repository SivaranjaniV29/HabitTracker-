# 📱 Habit Tracker

A simple mobile application for creating and tracking daily habits.

## 🛠️ Developed Using

- MIT App Inventor
- Android

## ✨ Features

- ➕ Create habits
- 🗑️ Delete habits
- 📅 Track daily habits
- 📊 View habit progress
- ✅ Mark habits as completed
- 📈 Calculate completion percentage
